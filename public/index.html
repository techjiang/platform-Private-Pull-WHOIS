SIXTEEN TOOLS · ONE API

十六种域名情报工具

WHOIS

域名 WHOIS 查询

查询任意域名的注册人、注册商、注册与到期日期、EPP 状态、DNS 服务器和 DNSSEC 状态。

GET /v1/whois/{domain}
RDAP

RDAP 结构化查询

直连注册局 RDAP 服务，返回现代 WHOIS 继任者的结构化注册数据，字段稳定、易于程序处理。

GET /v1/rdap/{domain}
DNS

DNS 记录查询

查询 A、AAAA、MX、TXT、NS、CNAME、SOA、SRV、CAA 记录，也可一次拉取全部记录。

GET /v1/dns/{domain}?type=MX
IP

IP 地址归属查询

查询 IPv4 与 IPv6 的 PTR 反向解析、所属网络、组织、国家/地区与注册时间等 RDAP 数据。

GET /v1/ip/{address}
UPTIME

网站可用性检查

检查网站当前是否可访问，返回 HTTP 状态、响应延迟、重定向后的最终地址与检查时间。

GET /v1/uptime?target=example.com
HISTORY

域名历史快照

对比注册商、注册人、DNS 服务器与状态变化。数据来自本站查询快照，自功能启用后持续积累。

GET /v1/history/{domain}
NS LOOKUP

名称服务器反查

输入名称服务器，查看本站索引中由它托管解析的域名，并统计注册商分布。

GET /v1/nameservers/{host}
REGISTRARS

注册商目录

合并 IANA Registrar IDs 与 ICANN 认证注册商列表，支持按国家与状态筛选，并展示本站索引中关联的域名数量。

GET /v1/registrars
ICP

ICP 备案查询

查询中国大陆 ICP 备案：网站备案号、主体备案号、主办单位、单位性质与审核时间。结果优先由本站持久化缓存返回，缓存未命中时才回源公开备案数据。

GET /v1/icp/{domain}
TLS

TLS 证书检查

本站直接与目标端口完成 TLS 握手，读取证书颁发者、有效期、SAN、指纹、协议与加密套件。不依赖第三方检测服务。

GET /v1/tls/{host}
MAIL

邮件安全记录

本站直接查询 DNS 并解析 SPF、DMARC、DKIM 与 MX，逐项给出通过、建议改进或缺失，完全自研解析。

GET /v1/mail/{domain}
HTTP

HTTP 安全响应头体检

直连目标站点读取响应头，检查 HSTS、CSP、点击劫持防护、MIME 嗅探、Referrer-Policy、COOP 与 Cookie 安全属性，给出评分与逐项建议。

GET /v1/http/{target}
PROPAGATION

DNS 多解析器传播对比

同时向阿里 DNS、DNSPod、Cloudflare 与 Google DNS 发起查询，对比解析结果是否一致，快速判断解析是否已经传播完成。

GET /v1/dnsprop/{domain}?type=A
HEALTH

域名健康评分

把注册信息、DNS、HTTPS 证书与邮件安全四个维度各 25 分汇总为 100 分，输出等级、检查项与可执行的改进建议。

GET /v1/health/{domain}
AVAILABILITY

批量可注册查询

一次最多检测 10 个域名，优先查询注册局 RDAP、未覆盖时回退 WHOIS，返回可注册状态、注册商与关键日期。

GET /v1/available?domains=a.com,b.net
CERT CHAIN

证书链导出

导出目标端口返回的完整证书链，包含每张证书的主体、颁发者、有效期、SHA-256 指纹与 PEM，可直接用于运维排查。

GET /v1/tls/{host}/chain
